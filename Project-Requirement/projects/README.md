# DocuTrust DevSecOps Track — Project Briefs

The nine-project DevSecOps portfolio for **DocuTrust**, split out of the original portfolio PDF into one readable markdown file per project.

## The Three Chains

- **Chain A — Detect** (Projects 1–3): find what's wrong with the code, its dependencies, and its runtime behavior.
- **Chain B — Prove** (Projects 4–6): prove where an artifact came from and that nothing tampered with it.
- **Chain C — Validate and Mature** (Projects 7–9): keep all of it holding up over time, and score it honestly.
